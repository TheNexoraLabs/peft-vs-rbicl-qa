# Uploading this repository to GitHub

The archive root contains the repository files. Extract it, then copy the contents of this folder into a local clone of `https://github.com/TheNexoraLabs/peft-vs-rbicl-qa`. Review the diff and secrets scan before committing.

Suggested first commit message: `Initial public research artifact release`.

Do not upload the ZIP archive itself as the repository contents. Upload the extracted folders and files so GitHub can render the README, notebooks, CSV tables, and CITATION.cff.
